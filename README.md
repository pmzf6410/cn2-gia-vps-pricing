### 月付一定比年付贵吗？

同款套餐折算下来月付通常更贵，但它的价值在于试错成本。一个参考：搬瓦工最便宜的GIA年付套餐46.59美元/年，而香港GIA月付89.99美元，两者机房不同不能直接换算，但月付确实能把“选错线路”的损失控制在一个月。

### 流量用超了会怎样？

看商家的规则。ByteVirt超流量后限速到1Mbps，机器保留但速度几乎不可用；搬瓦工香港款每月500GB@1Gbps；丽萨主机的常规套餐按固定流量计，两款不限流量套餐则没有这个顾虑。下单前把月用量估清楚，比事后补救省事。

### CN2 GIA和普通CN2、163骨干差在哪？

163骨干是电信的普通出口，晚高峰容易拥堵；CN2 GT只在部分路段走CN2；CN2 GIA全程走CN2且优先级最高，大陆三网访问的延迟和稳定性最好。这也是GIA套餐普遍比普通线路贵的原因。
